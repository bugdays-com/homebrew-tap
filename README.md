# Homebrew Tap for Bug Days

This is the official Homebrew tap for Bug Days tools.

## Installation

```bash
brew tap bugdays-com/tap
brew install holy-cors
```

Or in one command:

```bash
brew install bugdays-com/tap/holy-cors
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| holy-cors | A fast CORS proxy for developers |

## Updating

```bash
brew update
brew upgrade holy-cors
```
